# Camacho Contracting Services — Website Prototype

A single-page, mobile-first marketing site for **Camacho Contracting Services**
(Omar C. Camacho, Licensed Plumber — License #JP507184), serving Marietta, GA
and the greater Atlanta metro.

Built with pure HTML, CSS, and vanilla JavaScript. No build step, no
frameworks. The only external dependency is Google Fonts (Inter + Oswald).

## Files

| File | Theme | Use |
|------|-------|-----|
| `index.html` | **Deep navy blue + gold/amber** | Primary version |
| `index-charcoal.html` | **Dark charcoal + orange** | Comparison variation |

Both files are identical in layout and content — only the color palette
differs — so Omar can open each and pick the look he prefers. To make one of
them the live site, just keep that file as `index.html`.

## How to view it

Open either `.html` file in any web browser (double-click it), or drag the
folder into a [Vercel](https://vercel.com) deploy. No server needed.

## What's included (sections)

1. **Hero** — headline, tap-to-call phone button, and "Book a Visit" CTA
2. **Services** — Plumbing · Remodeling · Drain Cleaning
3. **Why Camacho** — licensed & insured, local, honest pricing, fast response
4. **How It Works** — Call/Book → We Assess → Problem Solved
5. **Booking** — placeholder box ready for a Calendly embed
6. **Reviews** — three sample 5-star reviews
7. **Contact / Footer** — phone, email, address, license number
8. **Floating chat button** — UI placeholder for the future AI assistant

## Editing the content (no coding needed)

Open the file in any text editor and search for these terms:

- **Phone number** — search for `678`
- **Email** — search for `Atlantapro.plumbing@gmail.com`
- **Address** — search for `1590 Oak Creek`
- **Services / Reviews** — look for the big comment banners
  (`SERVICES SECTION`, `REVIEWS SECTION`, etc.)

## Things that are placeholders (not yet functional)

- **Chat widget** — visual only; shows a "coming soon" message when clicked.
- **Online booking** — the booking section has a marked spot for a Calendly
  embed. Instructions for adding your Calendly link and script tag are in the
  code comments inside the `BOOKING SECTION`.

This is a visual prototype only — there is no backend.
